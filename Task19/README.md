# Sample Git Project

This project demonstrates basic Git operations.

## Steps

1. Initialize repo:
   git init

2. Add files:
   git add .

3. Commit:
   git commit -m "Initial commit"

4. Create new branch:
   git branch feature

5. Switch branch:
   git checkout feature

6. Merge branch:
   git checkout main
   git merge feature

7. Connect to GitHub:
   git remote add origin https://github.com/your-username/git-sample-project.git

8. Push:
   git push -u origin main
